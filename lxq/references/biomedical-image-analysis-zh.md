# 生物医学图像分析

用于显微图像（荧光、共聚焦、组织病理、电子显微镜）、三维医学影像和时序图像的量化、分割、检测、追踪与模型验证。根据任务加载现有 [分析 QC](analysis-qc.md) 或 [图像与图表 QC](figure-qc.md)。需要查找方法原文、设计对照或复核历史基准时，查阅 [文献学习笔记](biomedical-image-analysis-literature-zh.md)。

## 明确目标和图像条件

- 定义目标对象和主终点，如细胞核计数、标记信号面积分数、到细胞核边界的距离、病灶检出率或运输速度。记录 2D、3D 或时序维度、样本层级和对照设计。
- 保留原图和采集元数据，核对通道和标记、像素或体素大小、Z 步长、帧间隔、配准、曝光、饱和、视野选择和批次。物理标定缺失时，距离或面积限于相应像素单位，并标记缺失来源。
- 记录原图到掩膜、对象表和样本汇总表的对应关系。量化所用的背景扣除、平场校正、阈值和排除规则应可追溯。定量强度时保留原始或有明确校正记录的信号。

## 按目标和标注选择基线

| 目标 | 候选基线和验证 |
| --- | --- |
| 细胞体或细胞核的实例分割与计数 | 在图像条件适用时比较阈值与分水岭、Cellpose 或 StarDist。H&E 核分割可考虑 HoVer-Net。用目标样本检查粘连、误拆和漏检。 |
| 稀疏小目标定位 | 比较局部峰值或连通域基线与候选检测模型。若先分割组织或细胞范围，验证自动上游掩膜造成的小目标漏检。 |
| 少量像素级标注或仅有图像级标签 | 前者可比较随机选样和按不确定性与代表性选样的主动学习，并记录真实标注成本。后者可评估多实例分类，局部定位、计数和面积需要独立的局部人工参考。 |
| MRI、CT 或其他体数据的结构分割 | 根据体素间距、数据规模和目标比较 2D 与 3D U-Net 或 nnU-Net。将预处理、重采样和调参限制在各数据分区允许的范围内。 |
| 线粒体标记定位、形态与动态 | 固定图可测标记信号面积或体积分数、到核或细胞边界的距离。图像分辨率足以解析分支时可比较 MiNA 或 MitoGraph 的形态量。运动速度、停留及分裂融合事件需要校准的时间序列和追踪验证。 |

## 验证模型和最终测量

1. 以受试者、供体、动物或独立培养重复等来源样本分组。同源图块、相邻切片、重复访视或帧跟随同一来源。预处理参数和阈值使用训练或验证分区确定。跨中心、仪器或染色批次的适用性用对应留出数据检验。
2. 用代表性人工参考验证，覆盖低信号、密集、边缘及不同批次。语义分割检查重叠与边界，实例和稀疏目标检查对象匹配、漏检和假阳性。报告最终计数、距离、面积或形态测量与人工参考之间的偏差。
3. 从对象表回到实际实验单位做组间推断，按设计汇总或建模样本、视野与对象的依赖。标记信号和静态形态支持对应的空间表型。功能或机制结论需要对应实验和证据。
